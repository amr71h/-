How to install presets?

  1. Download the presets to your computer.
  2. Open Adobe Lightroom Classic.
  3. Go to the Develop module.
  4. In the Presets panel, right-click and choose Import.
  5. Find the downloaded .xmp file and select Import.
  6. The preset will appear in the list on the left.
